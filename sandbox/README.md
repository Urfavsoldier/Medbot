# Damumed Sandbox

Локальный статический mock-интерфейс для проверки MedBot Chrome Extension.

## Как запустить

Откройте `sandbox/index.html` в Chrome или запустите любой статический сервер из корня проекта.

```powershell
python -m http.server 8080
```

Затем откройте:

```text
http://localhost:8080/sandbox/
```

## Демо-команды для MedBot

- Открой первичный прием Иванова
- Жалобы на головную боль и слабость
- Объективно мышечный тонус снижен
- Назначить массаж и ЛФК
- Сформируй расписание на 9 рабочих дней
- Поставь выполнено по массажу
- Запиши дневник процедуры: ребенок перенес процедуру спокойно
